# 06 — Agent Factory

## Purpose

Let Sentinel create, configure, evaluate, run, and manage specialist agents using reusable definitions and controlled capabilities.

## Scope

- Agent manifests defining purpose, model, instructions, tools, and limits.
- Template-based agent creation.
- Agent lifecycle and version tracking.
- Capability and configuration validation before execution.
- Evaluation tests before an agent is approved for real tasks.
- Observability for agent runs and outcomes.

## Related issues

- [#53 — Agent Factory lifecycle](https://github.com/MD0210/Sentinel-AI/issues/53)

## Status

**Planned.** This depends on a functioning Core, tool contracts, and a proven specialist-agent workflow. Do not treat generated agent instructions as trusted code or grant new agents unrestricted permissions.
