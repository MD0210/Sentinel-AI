# 05 — AI Development Team

## Purpose

Coordinate specialist agents to help turn a product idea into a tested, reviewable software change.

## Initial specialist roles

- **Product Manager:** clarifies goals, user stories, and acceptance criteria.
- **Architect:** proposes system design and records trade-offs.
- **Developer:** prepares scoped code changes.
- **QA:** designs tests and reports failures.
- **Security Reviewer:** reviews risks and permission boundaries.
- **DevOps:** maintains CI/CD and release preparation.

## Scope

- Define task contracts, expected outputs, and handoff rules.
- Have Core assign a well-bounded task to one specialist.
- Collect and validate the specialist's result.
- Let Core synthesize results and request revisions when needed.
- Keep repository changes reviewable and require human approval for merges and releases.
